# Ecolshop

Ecolshop is a modern e-commerce web application built with React.
The project provides a complete shopping experience including product browsing, search, filtering, wishlist, cart management, authentication, and checkout.

## Features

* Modern and responsive homepage
* Product search
* Product categories
* Product filtering by price, rating, and brand
* Product pagination
* Product details page
* Product color and size selection
* Product quantity management
* Shopping cart
* Wishlist
* Cart and wishlist persistence
* User authentication
* User profile
* Logout functionality
* Checkout page
* Cash and card payment selection
* Form validation
* Responsive design
* Custom 404 Not Found page
* Client-side navigation without page reload

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/ecolshop.git
```

Navigate to the project folder:

```bash
cd ecolshop
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.
